\section{Determinacy of the Selected Profile Assignment}
\label{sec:determinacy}
% =============================================================================

Sections~\ref{sec:inventory}--\ref{sec:profiles} specify a finite catalog of
carrier--basis pairs and proposed transformation-classification profiles.
This section asks whether the catalog assigns a named profile to each
selected pair without ambiguity.
This is an internal property of the specified assignment.

% -----------------------------------------------------------------------------
\subsection{Core Carrier--Basis Pairs}
\label{subsec:core_carrier_basis_pairs}
% -----------------------------------------------------------------------------

\begin{definition}[Core carrier--basis pair]
\label{se200.def.CoreCarrierBasisPair}
A \emph{core carrier--basis pair} is one of the selected carrier-kind
and candidate identity-basis combinations displayed below.
The arrows
record the profile names assigned within this construction:
\[
\begin{array}{rcl}
\text{obligation-bearer with responsibility-bearing identity} &\mapsto& \OBL,\\
\text{occurrence with realization-and-provenance identity} &\mapsto& \OCC,\\
\text{record with descriptive-record identity} &\mapsto& \REC,\\
\text{plain referent with locus-fixed identity} &\mapsto& \LOC,\\
\text{plain referent with object-fixed identity} &\mapsto& \OBJ,\\
\text{scope with extension-fixed identity} &\mapsto& \SCOPEE,\\
\text{scope with structure-fixed identity} &\mapsto& \SCOPES,\\
\text{rule with content-fixed identity} &\mapsto& \RULEC,\\
\text{rule with structure-fixed identity} &\mapsto& \RULES.
\end{array}
\]
\end{definition}

The carrier kinds listed first have one candidate basis each;
the others have two, motivated by the conditional comparisons in
Section~\ref{sec:algebra}.

\begin{definition}[Core regime assignment]
\label{se200.def.CoreRegimeAssignment}
The \emph{core regime assignment} $A$ maps each selected core
carrier--basis pair to the named classification profile indicated by
the corresponding arrow in Definition~\ref{se200.def.CoreCarrierBasisPair}.
Its codomain is the selected profile catalog in Section~\ref{sec:profiles}.
\end{definition}

The assignment is stipulated as part of the finite construction.
It does not choose or justify a basis for an actual referent.

% -----------------------------------------------------------------------------
\subsection{Existence}
\label{subsec:determinacy_existence}
% -----------------------------------------------------------------------------

\begin{lemma}[Assignment existence]
\label{se200.lem.CoreExistence}
Every selected core carrier--basis pair has an assigned profile under $A$.
\end{lemma}

\begin{proof}
Definition~\ref{se200.def.CoreCarrierBasisPair} lists all selected
pairs and gives an image for each.
By
Definition~\ref{se200.def.CoreRegimeAssignment}, $A$ is defined on
every pair in its stated domain.
\end{proof}

% -----------------------------------------------------------------------------
\subsection{Uniqueness}
\label{subsec:determinacy_uniqueness}
% -----------------------------------------------------------------------------

\begin{lemma}[Assignment uniqueness]
\label{se200.lem.CoreUniqueness}
Each selected core carrier--basis pair has exactly one assigned profile
under $A$.
\end{lemma}

\begin{proof}
Each pair occurs exactly once on the left-hand side of the displayed
assignment in Definition~\ref{se200.def.CoreCarrierBasisPair}, with
one profile name on the right-hand side.
The definition of $A$ assigns
no additional value to that pair.
Hence its image under $A$ is unique.
\end{proof}

% -----------------------------------------------------------------------------
\subsection{Determinacy Theorem}
\label{subsec:determinacy_theorem}
% -----------------------------------------------------------------------------

\begin{theorem}[Core regime assignment]
\label{se200.thm.CoreRegimeAssignment}
For each carrier--basis pair in the selected catalog, there exists
exactly one named classification profile assigned to it by $A$.
\end{theorem}

\begin{proof}
Existence is Lemma~\ref{se200.lem.CoreExistence}; uniqueness is
Lemma~\ref{se200.lem.CoreUniqueness}.
\end{proof}

This theorem records determinacy of a defined, finite assignment.
It does not derive the assignment from the neutrality constraint,
establish the scientific correctness of its classification entries,
or show that the assigned profile yields a warranted strict-identity
relation on real-world referents.
Other candidate profiles or identity
bases may be relevant outside this selected catalog.

% -----------------------------------------------------------------------------
\subsection{Limits of Basis Declaration}
\label{subsec:basis_declaration_failure}
% -----------------------------------------------------------------------------

A carrier-kind label alone does not select one profile when the
catalog contains more than one candidate basis for that kind.
For example, a scope may be examined under extension-fixed or
structure-fixed criteria, a rule under content-fixed or
structure-fixed criteria, and a plain referent under locus-fixed
or object-fixed criteria.
Supplying the corresponding basis label
makes the input to $A$ unambiguous \emph{within this catalog}.

That is not the same as establishing which basis is appropriate for
a particular referent.
A declared basis needs independently justified
individuation and persistence conditions, and each proposed
transformation classification needs an adequate interpretation.
Even the carrier kinds represented by only one profile in this
catalog may admit other legitimate identity bases.

Consequently, a possible conformance check could verify whether a
system discloses a selected basis and applies its declared profile
consistently.
It could not, on that evidence alone, certify the
basis's scientific adequacy or the truth of its identity judgments.
This is the boundary of the determinacy result proved here.
